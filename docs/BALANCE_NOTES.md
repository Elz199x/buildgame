# บันทึกการออกแบบและความสมดุล (Design & Balance Notes)

เอกสารนี้สรุป "ทำไมตัวเลขเป็นแบบนี้" ของสกิล Novice และคลาสแรกทั้ง 4 (Swordman / Thief / Archer / Mage) ใน Skill Lab ผลการวัดจริงรอบล่าสุดอยู่ที่ `docs/BENCHMARK_REPORT.md` (สร้างอัตโนมัติ) ตารางสกิลครบอยู่ที่ `docs/SKILL_TABLES.md` ส่วนบันทึกร่างต้นฉบับอยู่ใน `docs/design-notes/` (`20-…`, `21-…`)

## 1. แหล่งแรงบันดาลใจ (ศึกษาจากเกม)

- **Ragnarok Online:** สกิลคลาสแรกเป็นต้นไม้พร้อมเงื่อนไข (เช่น Bash ฯลฯ), Job Level แยกจาก Base Level, Novice เรียน Basic Skill ก่อนเปลี่ยนอาชีพที่ Job Lv.10
- **MapleStory:** สกิลแบ่งเป็น passive/active/buff ชัด มีเลเวลสกิลและ mastery
- **Ghost Online:** เก็บข้อมูลได้น้อย (ใช้เป็นแนวคิดทั่วไป)
- หมายเหตุ: หน้า irowiki ของ Bash เปิดไม่ได้ตอนค้น จึงใช้ข้อมูลหน้า Swordman (Bash 130–400% ATK) เป็นฐานของ `swBash`

## 2. หลักการออกแบบ

1. **Novice = "ลิ้มลองสายอาชีพ"** แต้มจำกัด (9 แต้ม ต่อสกิลรวม 22 เลเวล = ซื้อได้ 41%) แบ่ง 3 สาย: เอาตัวรอด / สู้เบื้องต้น / ลิ้มลองสายอาชีพ (4 สกิล 1 เลเวล ให้ของเล็ก ๆ ที่ชี้ไปทางนักดาบ/โจร/นักธนู/จอมเวท) — **ค่าต่อแต้มของ Novice ≈ 40% ของคลาสแรก** เพื่อไม่ให้ Novice เก่งเกินจน "ไม่อยากเปลี่ยนอาชีพ"
2. **นักดาบ = 15 สกิล (passive 7 / active 4 / buff 4(buff 2, toggle 1, trigger 1)) รวม 78 เลเวล เทียบ 49 แต้ม** (ซื้อได้ 63%) → ต้องเลือกบิลด์
3. **3 สายของนักดาบ:** สายดาบ (ดาเมจ), สายโล่ (ทน), สายบ้าคลั่ง (เสี่ยงแลกแรง)
4. **Tier gate ตาม Job Lv:** T1=2 · T2=10 · T3=25 · T4=40 (capstone)
5. **ทรัพยากรไม่ใช่แค่ SP:** นักดาบ SP น้อย แต่มี **คูลดาวน์** และ **HP เป็นต้นทุน** (Magnum จ่าย HP 4%, Berserk ดูด HP ต่อวินาที)
6. **ครบ 5 ชนิดสกิล** (passive / active / buff / toggle / trigger) เพื่อทดสอบว่าโครงสร้างข้อมูลรองรับ
7. **ช่องเปิดไว้ต่อยอด:** `hooks` (stun, knockback, partyShare), `group` (สถานะแทนที่กัน), `requires` หลายข้อ (AND)

## 3. การตรวจ balance ที่ทำไว้ (นักดาบ Lv50 ATK 40 / HP 1904 / SP 384 / 1.25 ครั้งต่อวินาที)

| หัวข้อ | ผลตรวจ | การตัดสินใจ |
|---|---|---|
| Bash Lv10 ที่คูลดาวน์ 3 วิ | เพิ่ม DPS ราว **+80%** เหนือตีธรรมดา | ใช้ CD 3 วิ; SP ใช้ 6→10 ตามเลเวล |
| SP ที่ใช้ Bash ต่อเนื่อง | SP 384 อยู่ได้ราว **115 วินาที** | ตั้ง `spRegen` ชีต 1.5/วิ (ตอนวัดซ้ำ: Striker ลงท้าย SP เหลือแทบ 0 → ผู้เล่นต้องเลือกใช้ SP) |
| Berserk แบบเดิม "DEF −30%" | ทำให้ดาเมจที่รับเพิ่มแค่ **2.8–4.9%** (เพราะสูตร soft-DEF) → ไม่รู้สึกถึงราคาที่จ่าย | **เปลี่ยนเป็น `damageTaken` +5%/Lv** (Lv5 = +25%) + HP ไหล 0.3%/วิ + ปิดเองเมื่อ HP < 15% |
| `swSoul` (capstone ATK แบน) | +12/Lv แรงเกิน | **ลดเหลือ +9/Lv** (Lv3 = +27) |
| บัฟ ATK% ซ้อนกัน (Battle Cry + Berserk + Last Stand + Magnum aftermath) | รวมแล้วอาจเกิน 60%+ | เพิ่ม **`buffPercentCap.atk = 0.6`** (passive ไม่โดนจำกัด) |
| Provoke | ลด DEF เป้า 6%/Lv + เพิ่ม ATK เป้า 4%/Lv (แลก: มอนสเตอร์ตีแรงขึ้น) | ใช้ `group:'provoke'` กันซ้อน |
| Last Stand (trigger) | HP ≤ 25% เปิด ATK +8%/Lv ปิดเมื่อ HP > 50% CD 90 วิ | ผูกกับ Berserk Lv3 เพื่อให้เป็นสายเสี่ยงเดียวกัน |

## 4. ผลวัดจริงจากตัวจำลอง (สรุป; ตัวเลขเต็มดู BENCHMARK_REPORT.md)

120 วินาที, seed 1, ดัมมี่ธรรมดา ไม่สวนกลับ:
- **นักดาบ:** Striker ≈ 297 DPS · Berserker ≈ 217 · Guardian ≈ 115
- **โจร:** Assassin ≈ 328 DPS · Venom Phantom ≈ 227
- **นักธนู:** Sharpshooter ≈ 370 DPS · Ranger ≈ 264
- **จอมเวท:** Arcanist ≈ 406 DPS · Elementalist ≈ 304
- **ชาวบ้าน:** 3–4 DPS

จุดเด่นของการออกแบบโจร / นักธนู / จอมเวท (คลาสละ 15 สกิล = 78 เลเวล, 3 สาย, 4 Tiers ที่ Job Lv 2/10/25/40, ครบ 5 ชนิดสกิล):
- **โจร (Thief):** สายกริช / สายเงา & หลบหลีก / สายพิษ & เล่ห์กล — เน้น ASPD + Phys Crit + FLEE สูง เมื่อดัมมี่สวนกลับเสีย HP น้อยที่สุดในกลุ่ม DPS (1,475–1,848 HP ใน 120 วิ) และมีพิษลด DEF + เพิ่ม `damageTaken` เป้าหมาย
- **นักธนู (Archer):** สายยิงเร็ว / สายซุ่มยิง / สายพราน & กับดัก — ผูกกับอาวุธ `bow`, มีทั้งยิงเป้าเดียว (`arDoubleStrafe`, `arPiercingShot` คิด ATK+DEX ไม่พลาดเป้า) และ AoE (`arArrowShower`) พร้อมกับดักลด FLEE/DEF
- **จอมเวท (Mage):** สายเวทธาตุ / สายอาร์เคน & คริเวท / สายมานา & ป้องกัน — ดาเมจเวท 100% จากสกิล (ไม่พึ่งตีธรรมดา), ผูกกับระบบ Magic Crit Triad (`magicCrit`, `mdefIgnore`, `critDmg`), มี `mgEnergyCoat` ลดดาเมจกายภาพ และตั้งเพดาน `buffPercentCap.matk = 0.6`คู่กับ `atk`

ข้อสังเกต / ประเด็นที่ยังเปิดอยู่ (ควรตัดสินใจเป็นรอบต่อไป):

1. **Guardian (โล่) DPS ราว 39% ของ Striker** — เป็นสายทน แต่ยังไม่มีระบบ aggro/ปาร์ตี้ให้ความทนมีค่า และ Shield Bash ติดคอขวด SP → ควรเพิ่ม threat/taunt หรือยกค่าความทนในสถานการณ์หลายเป้า
2. **บิลด์ที่ HP ไหล (Berserker) ตายเมื่อมอนสเตอร์สวนกลับ** — Berserk ดูด HP 0.3%/วิ + รับดาเมจ +25% ขณะไม่มียา/ฮีล → ต้องมีระบบยาในตัวจำลอง ก่อนสรุปว่าสายนี้แรงเกินหรือเบาเกิน
3. **SP คือคอขวดหลักของ Striker** (SP ใช้ ~4.6–10 /วิ เทียบ regen 1.5) — ถ้าต้องการให้สกิลถูกใช้ครบคูลดาวน์ให้ลด `usage.sp` หรือเพิ่ม passive ฟื้น SP; ถ้าตั้งใจให้ต้องบริหาร SP ถือว่าตรงเจตนา
4. **ชาวบ้านตายเร็วมากกับบอส** — ตั้งใจ (Novice ไม่ได้ถูกออกแบบมาสู้บอส)
5. การตีธรรมดายังเป็น 25–55% ของดาเมจทุกบิลด์ → ถ้าต้องการให้สกิลเป็นพระเอก ให้ลดดาเมจตีธรรมดาหรือลด CD/SP ของสกิลหลัก
6. ผลทั้งหมดไม่รวม: ยา, หลายเป้า, ปาร์ตี้, cast time, สถานะ stun — ตัวเลขเหมาะกับการ **เทียบก่อน/หลังแก้** มากกว่าเป็นค่าสัมบูรณ์

## 5. ข้อแตกต่างระหว่าง Status Lab กับ Skill Lab ที่ต้องเก็บกวาดภายหลัง

| รายการ | Status Lab | Skill Lab |
|---|---|---|
| จิตวิญญาณนักรบบ้าคลั่ง | `swBerserkerSoul` +12 ATK/Lv (3 เลเวล) | `swSoul` +9 ATK/Lv (หลังตรวจ balance) |
| passive นักดาบ | 5 ตัว (Weapon Mastery, Toughness, Provoke Stance(crit), Shield Discipline, Berserker Soul) | 7 passive + 4 active + 4 buff/toggle/trigger (ออกแบบใหม่ ใช้ชื่อ/ตัวเลขต่างกันบ้าง) |
| จำนวนเลเวลสกิลสูงสุดต่อ passive | 5 (capstone 3) | ตามตารางใน SKILL_TABLES |
| ความเร็วตี | `100/(200−ASPD)` | เหมือนกัน |
| ATK ของอาวุธ | คำนวณจากสูตรอาวุธ+สเตตัส | มาจากชีต (นำเข้าจาก Status Lab) |

ก่อนรวมระบบสองฝั่งให้ตัดสินใจว่า "แหล่งความจริง" ของสกิลนักดาบคือ Skill Lab (แนะนำ) แล้วค่อยให้ Status Lab อ่านผลของ passive จากข้อมูลนี้
