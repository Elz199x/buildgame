> **บันทึกจากบทสนทนาออกแบบ** — เก็บไว้เป็นเหตุผล/แบบแผนต้นทาง ตัวเลขจริงให้ยึดไฟล์ข้อมูลและโค้ดเป็นหลัก (บางค่าถูกปรับภายหลัง ดู docs/CHANGELOG.md และ docs/BALANCE_NOTES.md)

**สรุปสั้น:** ชาวบ้าน (Novice) ควรมี **10 สกิล แบ่ง 3 สาย** (รอด / สู้เบื้องต้น / ลิ้มลองสายอาชีพ) ใช้ 9 แต้มจาก Job Lv.2–10 ซื้อได้ราว 41% ของ 22 เลเวลที่มี ติดตัวไปหลังเปลี่ยนอาชีพ และแต้มละ ≈ 40% ของพลังโหนด Tier 1 ของอาชีพแรก จึงไม่แย่งซีนอาชีพ

## 1. สกิลคลาสเริ่มต้นของแต่ละเกม

| เกม | สกิลเริ่มต้น | ข้อสังเกต |
|---|---|---|
| **RO** | Basic Skill (max 9 ปลดล็อกเทรด, อิโมจิ, นั่ง = รีเจนเพิ่ม, ห้องแชท, ปาร์ตี้, Kafra; Lv.9 = เปลี่ยนอาชีพ), First Aid (3 SP → 5 HP), Play Dead (สองตัวหลังต้อง Base Lv.4 + เควสต์) | แต้มสกิล 9 แต้ม = Basic Skill 9 เลเวลพอดี จึงไม่มีทางเลือกเลย เปลี่ยนอาชีพที่ Job Lv.10 |
| **MapleStory** | Three Snails (ยิงไกล ดาเมจ 10→40), Recovery (ฟื้น 24→72 HP ใน 30 วิ), Nimble Feet (วิ่งเร็ว +10→+20), Maple Return | 3 สกิล × 3 เลเวล = 9 เลเวล ก็ซื้อได้หมดเช่นกัน |
| **Ghost Online** | เริ่มเป็น **Peasant (ชาวบ้าน)** ได้ run / high jump / meditate / palm force | สกิลติดตัวไปคลาสถัดไป เปลี่ยนอาชีพที่ Lv.10 บางสกิลมาจากเควสต์ |

ข้อมูล Ghost Online หาได้น้อยที่สุด และตัวเลข cooldown/MP ของ MapleStory ไม่ตรงกันระหว่างแหล่ง ผมจึงใช้เป็นแนวทางเท่านั้น ไม่ได้ลอกตัวเลข

## 2. บทเรียนที่เอามาใช้

- **ทั้งสามเกมให้ครบ 3 บทบาท:** ฟื้นตัว / เคลื่อนที่-หนี / โจมตีเล็กน้อย
- **ข้อเสียที่ควรเลี่ยง:** RO และ Maple ซื้อสกิลได้หมดทุกตัว จึงไม่มีการตัดสินใจ และ Basic Skill ของ RO บังคับลงแต้มจนเป็น "แต้มตาย" ผมจึงให้สกิลพื้นฐานฟรีและทำให้ซื้อได้แค่ครึ่งเดียว
- **สิ่งที่ควรเอา:** สกิลติดตัวไปหลังเปลี่ยนอาชีพ (Ghost), สกิลขั้นสองต้องรอ Lv.4 (RO), สกิลฟรีที่มาจากเควสต์ (Ghost)

## 3. โครงสร้างที่เสนอ

**กติกา:** Job Lv.2–10 ได้ 1 แต้ม/เลเวล รวม 9 แต้ม ไม่คืนแต้มตอนเปลี่ยนอาชีพ อาชีพแรกใช้แต้มชุดใหม่แยกกัน

| สกิล | ชนิด | Max | เงื่อนไข | ผลต่อเลเวล |
|---|---|---|---|---|
| **สาย A: เอาตัวรอด** | | | | |
| ร่างกายชาวบ้าน | Passive | 3 | — | HP +3% |
| นั่งพักสมาธิ | Passive | 3 | — | HP regen +0.05/วิ, SP max +3% |
| ปฐมพยาบาล | Active | 3 | Job Lv.4 + ร่างกายชาวบ้าน Lv.1 | ฟื้น 2/3/4% max HP, SP 5, CD 15 วิ |
| **สาย B: สู้เบื้องต้น** | | | | |
| หมัดชาวบ้าน | Passive | 3 | — | ATK +2 (ยกเว้นไม้เท้า) |
| ไหวพริบชาวบ้าน | Passive | 3 | — | HIT +1, FLEE +1 |
| ปาก้อนหิน | Active | 3 | Job Lv.4 + ไหวพริบ Lv.1 | ยิงไกล ×1.0/1.2/1.4 ของ (0.6×DEX + 0.2×STR) ไม่ผูกอาวุธ, SP 3, CD 2 วิ |
| **สาย C: ลิ้มลองสายอาชีพ** (Max 1 ทุกตัว) | | | | |
| แขนแกร่ง → นักดาบ | Passive | 1 | — | ATK +2 |
| ย่องเบา → โจร | Passive | 1 | — | ASPD +1 |
| ตาไว → นักธนู | Passive | 1 | — | HIT +1.5 |
| จิตนิ่ง → จอมเวท | Passive | 1 | — | MATK +1.5% |

**สกิลฟรี (ไม่เสียแต้ม):** ฟังก์ชันพื้นฐาน (เทรด, ปาร์ตี้, แชท) ปลดตาม Base Lv., แกล้งตาย และกลับหมู่บ้านให้จากเควสต์ ตัดกับดัก Basic Skill ของ RO ทิ้ง เงื่อนไขเปลี่ยนอาชีพเหลือแค่ Job Lv.10 ตามที่คุณกำหนด

**ตัวอย่างบิลด์ 9 แต้ม:**
- **ลุย:** หมัดชาวบ้าน 3, ร่างกาย 3, แขนแกร่ง 1, ไหวพริบ 2
- **ถอยยิง:** ไหวพริบ 3, ปาก้อนหิน 3, ตาไว 1, ย่องเบา 1, นั่งพัก 1
- **ทน:** ร่างกาย 3, นั่งพัก 3, ปฐมพยาบาล 3

ผมไม่เสนอ "โบนัสสะพาน" (ลงสกิลลิ้มลองตรงสายแล้วได้แต้มอาชีพแรกฟรี) เพราะทุกคนจะเลือกตัวนั้นโดยไม่ต้องคิด

## 4. ตรวจ balance ด้วยสูตรจริง (นักดาบ Lv.50 บิลด์เริ่มต้น: ATK 40, HP 1,904)

- **งบต่อแต้ม:** หมัดชาวบ้าน +2 ATK/แต้ม เทียบ Weapon Mastery นักดาบ +5 ATK/แต้ม = **40%**
- **บิลด์ลุยเต็ม 9 แต้ม:** ATK +20%, HP +9% ส่วนอาชีพแรกใส่ Weapon Mastery เต็มได้ +62.5% เมื่อรวมกัน novice เพิ่มให้แค่ **+12.3%** ไม่เปลี่ยนภาพ
- **ปฐมพยาบาล Lv.3:** ฟื้น 76 HP ต่อ 15 วิ ≈ 5.1 HP/วิ เทียบ regen ธรรมชาติ 1.5 HP/วิ (≈3.4 เท่า) SP เต็ม 384 ร่ายได้ราว 77 ครั้ง
- **ปาก้อนหิน:** 32 / 38.4 / 44.8 เทียบสวิงดาบ 40 จึงเป็นตัวเลือกยิงไกล ไม่ใช่ตัวดัน DPS ทะลุเพดาน (ต้องวัดซ้ำหลังทำ engine จริง)
- **สกิลลิ้มลอง:** 40–50% ของโหนดอาชีพแรกต่อเลเวล แต่ Max 1 จึงเท่ากับ 8–10% ของโหนดเต็ม (ตาไวตั้ง +1.5 แทน +2 เพื่อให้เข้ากรอบ)

## 5. ผลต่อระบบที่มีอยู่

- **ทำได้ทันที:** สกิล passive ทั้ง 8 ตัว ใช้เป้าหมายที่มีอยู่แล้ว (hpPercent, hpRegenFlat, atkFlat, hitFlat ฯลฯ)
- **ต้องเพิ่ม:** ตัวเลข Job Level (Novice สูงสุด 10) และระบบงบแต้มสกิล
- **ต้องสร้าง engine ใหม่:** ปฐมพยาบาลกับปาก้อนหินเป็น Active (SP, cooldown, ตัวคูณดาเมจ) ซึ่งตอนนี้ simulator ไม่มี แต่ใช้โครง ICD ของ autospell ต่อยอดได้
- **ต้องย้าย/ลด:** passive universal 4 ตัวเดิม ควรยุบเข้าสายนี้และลดเลเวลลง ส่วน **Autospell Catalyst** ทำให้ชาวบ้านมี autospell ได้ ควรย้ายไปอยู่ในทรีอาชีพ

ผมแนะนำทำเป็น 3 เฟส: (1) Job Lv + งบแต้ม + passive 8 ตัว (2) Active engine + ปฐมพยาบาล/ปาก้อนหิน (3) สกิลฟรี/เควสต์

ให้เริ่มเฟส 1 ในตัวจำลองเลยไหม หรืออยากปรับโครงสร้างตรงไหนก่อน (เช่น จำนวนแต้ม หรือเรื่องไม่คืนแต้มตอนเปลี่ยนอาชีพ)?
