**สรุปสั้น:** นักดาบมี **15 สกิล (passive 7 / active 4 / buff 4) รวม 78 เลเวล** เทียบ 49 แต้มที่ได้จาก Job Lv.2–50 จึงซื้อได้ราว 63% แกนอัตลักษณ์คือ **SP น้อย ใช้ cooldown คุมจังหวะ และใช้ HP เป็นทรัพยากรที่สอง** แตกเป็น 3 สาย (ดาบ / โล่ / บ้าคลั่ง) ซึ่งเป็นจุดต่อยอดไปอาชีพที่ 2 ที่ Job Lv.50 ผมตรวจ prerequisite และตัวเลขกับสูตรจริงของ simulator แล้ว

## 1. สิ่งที่เอามาจาก RO และสิ่งที่ปรับ

RO Swordman มี 10 สกิลส่วนใหญ่ max 10 เช่น Bash 130–400% ATK, Magnum Break 120–300% (SP 30 + เสีย HP, +20% ดาเมจไฟ 10 วิ, ต้อง Bash 5), Provoke ลด DEF 10→55% แต่เป้าหมายตีแรงขึ้น 5→32%, Endure ต้อง Provoke 5, Berserk เป็นสกิลเควสต์ที่ Job Lv.30

ที่ผมปรับ:
- เก็บ Bash เป็นแกนหลัก 10 เลเวล ส่วนสกิลรองลดเหลือ max 5 ตามงบแต้มที่มี
- แยก "ท่าบ้าคลั่ง" เป็น buff ที่เปิด-ปิดได้
- เพิ่ม **กระแทกโล่** ให้สายโล่มี active เป็นของตัวเอง (RO ไม่มี)
- Endure ผูกกับสายร่างกาย ไม่ต้องผ่าน Provoke

## 2. กติกาการใช้งาน

- **ทรัพยากร:** SP (น้อย), HP (บางสกิลเสีย %), Cooldown (ตัวคุมหลัก) การใช้สกิลถือว่า **แทน 1 สวิงปกติ**
- **Buff:** แยกกลุ่ม (`stance` ไม่ซ้อนกันเอง, `aftermath`) ใช้ซ้ำคือรีเฟรชเวลา ไม่ซ้อนค่า
- **เพดาน:** ATK% จาก buff รวมกันไม่เกิน **+60%** (เหมือน cap ของ mitigation และ ASPD ที่มี)
- **Job Lv ขั้นปลดล็อก:** Tier1 = 2, Tier2 = 10, Tier3 = 25, Tier4 = 40

## 4. Schema ที่เปิดทางต่อยอด

| ช่องข้อมูล | ไว้ทำอะไร |
|---|---|
| `type` = passive / active / buff / toggle / trigger | ใช้ engine เดียวกันทุกอาชีพ |
| `requires[]` (หลายเงื่อนไข) + `jobLvReq` | ตอนนี้ simulator รองรับเงื่อนไขเดียว ต้องเปลี่ยนเป็น array |
| `weaponReq` / `needShield` | กรองตามประเภทดาเมจหรือ slot (เพิ่มจากตัวกรอง weaponClass ที่มี) |
| `usage{spCost[], hpCostPct[], cooldown, duration, range}` | ค่าใช้งานต่อเลเวล |
| `scale{base, step}` + `override[]` | แก้ทั้งตารางเลเวลจากสูตรเดียวใน backend |
| `effects[]` + source tag | ใช้ modifier ระบบเดิม ลบ buff ทั้งก้อนด้วย `removeModifiersBySource` ได้ |
| `buffGroup` / `stackRule` | stance, guard, aftermath · เข้า buff cap |
| `hooks`: statusChance, knockback, partyShare, secondJob | ช่องเปล่าไว้ต่อสตัน ปาร์ตี้ และอาชีพที่ 2 |

**ต่ออาชีพที่ 2:** แบ่งสกิลเป็น 3 สาย สายดาบ (ชำนาญ, สองมือ, Bash, ระเบิดคลื่นดาบ, ตะโกนศึก) · สายโล่ (ร่างกาย, ฟื้นตัว, วินัยโล่, กระแทกโล่, อดทน) · สายบ้าคลั่ง (จังหวะ, ยั่วยุ, ท่าบ้าคลั่ง, สู้ตาย, จิตวิญญาณ) เสนอเงื่อนไข "ลง ≥ 20 เลเวลในสายเดียว + Job Lv.50" จึงเลือกอาชีพที่ 2 ได้ บิลด์ตัวอย่างทั้งสามผ่านเกณฑ์นี้

**ของเดิมใน simulator:** 5 passive เดิมคงไว้ 4 ตัว ส่วน "ท่ายั่วยุ" เดิมควรเปลี่ยนชื่อเป็น "จังหวะเปิดช่อง" เพราะชื่อชนกับ Provoke ที่เป็น active จริงแล้ว

## 5. ผลตรวจ (นักดาบ Lv.50 บิลด์ lab, ATK 65 หลังใส่ชำนาญอาวุธ)

**บิลด์ตัวอย่าง 49 แต้ม (ตรวจ prerequisite ผ่านหมด):**

| บิลด์ | การลงแต้ม | Job Lv สูงสุดที่ต้องถึง |
|---|---|---|
| ดาบสองมือ | ชำนาญ 5, สองมือ 5, จังหวะ 5, Bash 10, ยั่วยุ 3, ระเบิดคลื่นดาบ 5, ตะโกน 5, จิตวิญญาณ 3, ท่าบ้าคลั่ง 5, สู้ตาย 3 | 40 |
| ดาบ+โล่ | ร่างกาย 5, ฟื้นตัว 5, วินัยโล่ 5, อดทน 5, Bash 9, กระแทกโล่ 5, ยั่วยุ 5, ชำนาญ 5, ตะโกน 5 | 25 |
| บ้าคลั่ง | ชำนาญ 5, จังหวะ 5, Bash 8, ยั่วยุ 3, ท่าบ้าคลั่ง 5, สู้ตาย 5, จิตวิญญาณ 3, ร่างกาย 5, ฟื้นตัว 5, อดทน 5 | 40 |

**ตัวเลขที่ได้ และจุดที่ผมปรับตามผล:**
- **Bash:** Lv1 เพิ่ม DPS +8%, Lv5 +40%, Lv10 **+80%** ที่กิน SP 3.3/วิ ทำให้ SP 384 หมดใน ~115 วิ **simulator ยังไม่มีสูตร SP regen** แนะนำ ~1.5 SP/วิ ซึ่งทำให้หมุนสกิลได้ราว 45% ของเวลา เข้ากับคอนเซ็ปต์ SP น้อย
- **ท่าบ้าคลั่ง:** ถ้าใช้ "DEF −30%" แบบ RO จะเพิ่มดาเมจที่รับแค่ **2.8–4.9%** (DEF 30–55) แทบไม่มีโทษ เพราะสูตร soft-DEF ลดเฉพาะ DEF ต่ำ ผมจึงเปลี่ยนเป็น "ดาเมจที่รับ +5%/Lv"
- **จิตวิญญาณนักรบบ้าคลั่ง:** +12/Lv × 3 = +36 ATK = **90% ของ ATK ฐาน** เทียบ capstone นักธนู +24 (60%) จึงแนะนำลดเป็น +9/Lv (+27 = 68%)
- **Buff ซ้อน:** ตะโกน 20% + ท่าบ้าคลั่ง 30% + สู้ตาย 40% = 90% ถ้าไม่มี cap จะได้ ×1.90 ตั้ง cap 60% เหลือ ×1.60
- **ยั่วยุ Lv5:** ดัมมี่ DEF 40 ได้ดาเมจเพิ่มแค่ +3.7% แต่ DEF 200 ได้ +13.6% และ DEF 400 ได้ +20.7% จึงเป็นสกิลสำหรับเป้าเกราะหนา
- **กระแทกโล่ Lv5:** ได้ 182 เทียบ Bash Lv10 ที่ 260 (70%) และต้องลงสายโล่ราว 13 เลเวลก่อน จึงเป็น active ของสายทนที่ไม่แซง Bash
- **ระเบิดคลื่นดาบ Lv5:** เป้าเดียวเพิ่ม DPS แค่ +19% แลก HP 76 ต่อครั้ง จะคุ้มเมื่อโดน 3 เป้าขึ้นไป (simulator มีดัมมี่ตัวเดียว)
- **อดทน Lv5:** ลดดาเมจกายภาพรวมจาก 15.5% เป็น 36.6% (cap 80%)

ข้อควรระวัง: ตัวเลข DPS ประเมินจากการ "ใช้สกิลแทน 1 สวิง" และไม่นับ DEF ของเป้ากับ crit ต้องวัดซ้ำหลังมี skill engine จริง
